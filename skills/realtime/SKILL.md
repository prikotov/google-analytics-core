# GA4: realtime (сейчас на сайте)

## Когда использовать

- «Кто на сайте прямо сейчас» — активные пользователи за последние ~30 минут
- Проверка, что аналитика/GTM подключена: открыл сайт — realtime показывает заход
- Текущие страницы, страны и устройства активного трафика

## Запуск

```bash
php ga4.php [--site <name>] [--limit N]
```

| Опция | Описание | По умолчанию |
|-------|----------|--------------|
| `--site <name>` | Сайт из properties конфига | `default_site` |
| `--limit <n>` | Максимум строк на каждый срез | 50 |

Создаёт **четыре среза**: `realtime_pages_*` (страницы: activeUsers + screenPageViews),
`realtime_countries_*` (страны: activeUsers), `realtime_devices_*` (устройства),
`realtime_minutes_*` (поминутная динамика activeUsers). В консоль выводится
суммарное число активных пользователей.

## Примеры

```bash
php ga4.php                       # default_site
php ga4.php --site prikotov.pro
php ga4.php -s task.ai-aid.pro --limit 10
```

## Метрики и интерпретация

| Колонка | Смысл |
|---------|-------|
| `activeUsers` | Пользователи с событием за окно (последние ~30 минут) |
| `screenPageViews` | Просмотры страниц за окно |
| `minutesAgo` | Сколько минут назад: `0` — текущая минута, `29` — 29 минут назад |

- `activeUsers` в realtime ≠ пользователи за период в обычных отчётах: окно realtime
  ~30 минут, данные приходят с задержкой в несколько минут.
- Окно realtime — **последние 30 минут**, `dateRanges` в realtime-запросах не
  используется (API вернёт ошибку).
- Ноль активных пользователей — норма для малопосещаемых сайтов: это не ошибка
  подключения (проверяй подключение отдельным заходим на сайт под другим IP).
- Разрезы realtime ограничены официальной схемой: unifiedScreenName, country,
  city, deviceCategory, minutesAgo, eventName, appVersion, platform, stream*.
  **`sessionSource` в realtime-схеме v1beta нет** (проверено 13.11.2026: HTTP 400
  «sessionSource is not a valid dimension») — источник активного трафика берите
  из обычного отчёта ga4-traffic за сегодня.

## Отчёты

`ga4_reports/YYYY-MM-DD/realtime_{pages,countries,devices,minutes}_<timestamp>.{csv,md}`.

## Ошибки

- Нет конфига — скилл создаёт шаблон `ga4_config.json` и выводит инструкцию (exit 1).
- 400 с перечнем допустимых dimensions — используйте только realtime-измерения.
- 401 — удалите кэш `ga4_token.json`; 403 — назначьте сервисному аккаунту роль Viewer
  на свойство GA4; 429 — квоты Realtime API (2400 токенов/час на свойство).
