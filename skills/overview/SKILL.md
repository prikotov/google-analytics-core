# GA4: сводка по дням (overview)

## Когда использовать

- Общая динамика сайта: сессии, пользователи, просмотры по дням
- Оценка качества трафика: вовлечённые сессии, bounceRate, средняя длительность
- Быстрый ответ агенту на вопрос «как ведёт себя сайт за последнюю неделю/месяц»

## Запуск

```bash
php ga4.php [--site <name>] [--days N | --date1 D --date2 D] [--limit N]
```

| Опция | Описание | По умолчанию |
|-------|----------|--------------|
| `--site <name>` | Сайт из properties конфига | `default_site` |
| `--days <n>` | Последние N дней, включая сегодня | 28 |
| `--date1/--date2` | Явный период YYYY-MM-DD (оба или ни одного) | — |
| `--limit <n>` | Максимум строк | 90 |

Без `--site` берётся `default_site` из `ga4_config.json` (если в properties один сайт — он).

## Примеры

```bash
php ga4.php                                     # default_site, 28 дней
php ga4.php --site prikotov.pro --days 7        # 7 дней по сайту prikotov.pro
php ga4.php -s task.ai-aid.pro --date1 2026-11-01 --date2 2026-11-13
```

## Метрики в отчёте

| Метрика | Смысл |
|---------|-------|
| `sessions` | Сессии (визиты) за день |
| `totalUsers` | Уникальные пользователи за день |
| `screenPageViews` | Просмотры страниц |
| `engagedSessions` | Вовлечённые сессии: ≥10 сек, событие-конверсия или ≥2 просмотров |
| `bounceRate` | Доля невовлечённых сессий, **0–1** (0.45 = 45%) |
| `averageSessionDuration` | Средняя длительность сессии, **секунды** |

## Интерпретация

- **bounceRate GA4 = 1 − engagementRate.** Это НЕ «отказы» из Яндекс.Метрики:
  GA4 считает сессию вовлечённой, если она длилась ≥10 секунд, содержала конверсию
  или ≥2 просмотров. Поэтому bounceRate GA4 обычно заметно ниже «отказов» Метрики —
  сравнивать напрямую нельзя.
- `averageSessionDuration` — в секундах (245.3 ≈ 4 мин 5 сек). Ноль/мала при
  преобладании коротких невовлечённых сессий.
- Engagement-метрики (bounceRate, engagedSessions, duration) — сессионные: фильтрация
  по страницам/источникам распределяет сессию по всем её значениям измерения.

## Отчёты

`ga4_reports/YYYY-MM-DD/overview_<timestamp>.{csv,md}` в текущем каталоге —
строка на день, даты по возрастанию.

## Ошибки

- Нет конфига — скилл создаёт шаблон `ga4_config.json` и выводит инструкцию (exit 1).
- 401 — удалите кэш `ga4_token.json`; 403 — назначьте сервисному аккаунту роль Viewer
  на свойство GA4; 429 — квоты Data API, повторите позже.
