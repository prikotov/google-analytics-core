# GA4: топ-страницы (pages)

## Когда использовать

- Какие страницы самые популярные (просмотры, пользователи)
- Поведение на страницах: суммарное время вовлечённости, bounceRate
- Поиск проблемных страниц: много просмотров при высоком bounceRate и нулевом времени

## Запуск

```bash
php ga4.php [--site <name>] [--days N | --date1 D --date2 D] [--limit N]
```

| Опция | Описание | По умолчанию |
|-------|----------|--------------|
| `--site <name>` | Сайт из properties конфига | `default_site` |
| `--days <n>` | Последние N дней, включая сегодня | 28 |
| `--date1/--date2` | Явный период YYYY-MM-DD (оба или ни одного) | — |
| `--limit <n>` | Максимум строк | 50 |

## Примеры

```bash
php ga4.php                                     # default_site, 28 дней, топ-50
php ga4.php --site prikotov.pro --days 7 --limit 20
php ga4.php -s task.ai-aid.pro --date1 2026-11-01 --date2 2026-11-13
```

## Метрики в отчёте

| Колонка | Смысл |
|---------|-------|
| `pagePath` | Путь страницы (`/`, `/blog/post/…`) |
| `unifiedScreenName` | Название экрана/страницы (для веба — обычно title страницы) |
| `screenPageViews` | Просмотры страницы |
| `totalUsers` | Уникальные пользователи, видевшие страницу |
| `sessions` | Сессии, в которых страница показана |
| `userEngagementDuration` | Суммарное время вовлечённости на странице, **секунды** |
| `bounceRate` | Доля невовлечённых сессий со страницей, **0–1** |

## Интерпретация

- `userEngagementDuration` — **сумма**, не среднее. Среднее время на страницу ≈
  `userEngagementDuration / screenPageViews`. Время считается только во
  вовлечённые интервалы (вкладка активна), поэтому ≠ времени на странице Метрики.
- **bounceRate GA4 = 1 − engagementRate** и является **сессионной** метрикой:
  одна сессия с несколькими страницами повторяет свой bounceRate в каждой строке.
  Не суммируй bounceRate по страницам — интерпретируй только на уровне строки
  или фильтра. Это НЕ «отказы» Метрики (там отказ = визит с одним просмотром без
  активности; GA4 «прощает» сессии ≥10 секунд и конверсии).
- `unifiedScreenName` пустой для страниц без title — ориентируйся на `pagePath`.
- `(other)` в row для многомерных выборок — это кардинальность (ср. limit),
  у нас выборка по `pagePath` с сортировкой по просмотрам — практически не встречается.

## Отчёты

`ga4_reports/YYYY-MM-DD/pages_<timestamp>.{csv,md}`, сортировка по убыванию просмотров.

## Ошибки

- Нет конфига — скилл создаёт шаблон `ga4_config.json` и выводит инструкцию (exit 1).
- 401 — удалите кэш `ga4_token.json`; 403 — назначьте сервисному аккаунту роль Viewer
  на свойство GA4; 429 — квоты Data API, повторите позже.
