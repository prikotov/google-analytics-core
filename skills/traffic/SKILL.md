# GA4: источники трафика (traffic)

## Когда использовать

- «Откуда приходит трафик» — группы каналов (Organic Search, Direct, Referral…)
- Детализация по источник/канал: `google / organic`, `yandex / organic`, `(direct) / (none)`
- Качество трафика из каждого канала: вовлечённость, bounceRate, длительность сессии

## Запуск

```bash
php scripts/traffic.php [--site <name>] [--days N | --date1 D --date2 D] [--limit N]
```

| Опция | Описание | По умолчанию |
|-------|----------|--------------|
| `--site <name>` | Сайт из properties конфига | `default_site` |
| `--days <n>` | Последние N дней, включая сегодня | 28 |
| `--date1/--date2` | Явный период YYYY-MM-DD (оба или ни одного) | — |
| `--limit <n>` | Максимум строк (каналы: до 30, источники: до указанного) | 50 |

Создаёт **два отчёта**: `traffic_channels_*` (группы каналов) и
`traffic_sources_*` (детали источник/канал).

## Примеры

```bash
php scripts/traffic.php  # default_site, 28 дней
php scripts/traffic.php --site prikotov.pro --days 7 --limit 20
php scripts/traffic.php -s task.ai-aid.pro --date1 2026-11-01 --date2 2026-11-13
```

## Метрики в отчёте

| Метрика | Смысл |
|---------|-------|
| `sessions` | Сессии из источника |
| `totalUsers` | Уникальные пользователи из источника |
| `engagedSessions` | Вовлечённые сессии (≥10 сек / конверсия / ≥2 просмотров) |
| `bounceRate` | Доля невовлечённых сессий, **0–1** (0.45 = 45%) |
| `averageSessionDuration` | Средняя длительность сессии, **секунды** |

## Интерпретация

- `sessionDefaultChannelGroup` — системная группировка GA4 (Direct, Organic Search,
  Paid Search, Organic Social, Referral, Email, Unassigned…). «Unassigned» = события
  без атрибуции источника (часто measurement-ошибки или прямые технические заходы).
- Сравнивай каналы не только по объёму (`sessions`), но и по качеству: канал с
  высоким bounceRate (близко к 1) и короткой сессией даёт мало смысла, даже если
  сессий много.
- **bounceRate GA4 = 1 − engagementRate** — это НЕ «отказы» Метрики: сессия с одним
  просмотром, но длиной ≥10 секунд, в GA4 считается вовлечённой. Прямое сравнение
  с Метрикой некорректно.
- Атрибуция сессии — по первому источнику (last non-direct click по умолчанию),
  один визит = один источник.

## Отчёты

`ga4_reports/YYYY-MM-DD/traffic_{channels,sources}_<timestamp>.{csv,md}`,
сортировка по убыванию сессий.

## Ошибки

- Нет конфига — скилл создаёт шаблон `ga4_config.json` и выводит инструкцию (exit 1).
- 401 — удалите кэш `ga4_token.json`; 403 — назначьте сервисному аккаунту роль Viewer
  на свойство GA4; 429 — квоты Data API, повторите позже.
