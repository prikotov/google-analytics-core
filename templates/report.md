# Шаблон отчёта GA4

Используй эту структуру для аналитических отчётов по данным GA4. Данные бери
из CSV/MD, которые создают саб-скиллы в `ga4_reports/<дата>/`.

```markdown
# GA4: <вопрос или тема>

- Сайт: <имя> (<propertyId>)
- Период: <YYYY-MM-DD … YYYY-MM-DD>
- Источник: GA4 Data API v1beta, скилл google-analytics-core
- Дата отчёта: <YYYY-MM-DD>

## Обзор

| Показатель | Значение |
|---|---|
| Сессии | <сумма sessions> |
| Пользователи | <totalUsers> |
| Просмотры | <screenPageViews> |
| Bounce rate | <средневзвешенный 1 − engagement, 0–1 → %[]> |
| Средняя сессия | <секунды → «мин:сек»> |

## Динамика (если нужна)

| Дата | Сессии | Пользователи | Просмотры | Bounce |
|---|---|---|---|---|
| <YYYY-MM-DD> | <sessions> | <totalUsers> | <screenPageViews> | <bounceRate> |

## Топ каналов / источников

| Канал | Сессии | Пользователи | Bounce |
|---|---|---|---|
| <channel> | <sessions> | <totalUsers> | <bounceRate> |

## Топ страниц

| Страница | Просмотры | Пользователи |
|---|---|---|
| <pagePath> | <screenPageViews> | <totalUsers> |

## Выводы

- <1–3 вывода: объём и динамика трафика, лучшие/проблемные каналы и страницы>
- Ограничения: <что не покрыто — realtime-окно 30 минут, сессионные метрики,
  кардинальность выборок, отсутствие данных за сегодня на момент сбора>
```

Правила:

- Числа — только из ответа API, без оценок «с потолка»; пустой результат фиксируй
  как «нет данных за период», не как «трафика нет».
- bounceRate GA4 — доля невовлечённых сессий (0–1). Это НЕ «отказы» Метрики:
  сессия вовлечена при ≥10 сек, конверсии или ≥2 просмотрах. В выводах не смешивай.
- averageSessionDuration и userEngagementDuration — в секундах; для человека
  переводи в «мин:сек», в таблицах оставляй как в API.
- Сессионные метрики (bounceRate, engagedSessions, session-метрики) нельзя
  суммировать по строкам многомерных выборок — сумма «передвойняет» сессии.
